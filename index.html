02 About

I design and build digital experiences that connect considered UX with production-ready engineering — from SaaS dashboards and internal platforms to Shopify storefronts and the infrastructure behind them.

Most of the products I work on aren't simple. They carry real operational weight — marketplace data from a dozen sources, internal teams with conflicting permissions, catalogues that outgrow their own navigation. My job is to make that weight invisible to the person using it.

I work end to end. That means sitting with the actual workflow before opening Figma, designing a system rather than a screen, and then building it myself in React and Next.js so nothing gets lost between the design file and production. I care about the parts people notice last: how a table behaves at 400 rows, what an empty state says, whether a form tells you what went wrong before you submit it.

I also build the plumbing when a product needs it — MCP servers that pull live marketplace data into the tools that consume it, and the VPS, cloud and Hostinger environments those tools actually run on. Knowing how something deploys changes how you design it.
